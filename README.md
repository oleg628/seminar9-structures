# Семинар 9. Стек, очередь и дек на массиве

Решение заданий 10.1.1–10.1.5 по дисциплине «Алгоритмизация и программирование» (ИУ5, МГТУ им. Н.Э. Баумана).

Репозиторий содержит:

- краткие ответы на все пять заданий;
- C++17-реализацию стека, двух стеков в одном массиве, циклической очереди и дека;
- модульные тесты GoogleTest, включая сравнение с `std::deque` и `std::queue`;
- отчёт в форматах DOCX и PDF.

## Ответы на задания

### 10.1.1. Операции над стеком

Исходно `top = 0`. После `PUSH(4), PUSH(1), PUSH(3), POP, PUSH(8), POP`:

- `POP` возвращает `3`, затем `8`;
- итоговый `top = 2`;
- в стеке остаются `4` (дно) и `1` (вершина).

Значения `3` и `8` остаются в массиве, но уже не принадлежат стеку.

### 10.1.2. Два стека в одном массиве

Первый стек растёт от начала массива, второй — от конца:

```text
top1 = 0, top2 = n + 1
PUSH1: A[++top1] = x
PUSH2: A[--top2] = x
```

Переполнение возникает только при `top1 + 1 == top2`, то есть когда все `n` клеток заняты. Обе операции работают за `O(1)`.

### 10.1.3. Операции над очередью

Для `Q[1..6]` и последовательности `ENQUEUE(4), ENQUEUE(1), ENQUEUE(3), DEQUEUE, ENQUEUE(8), DEQUEUE`:

- `DEQUEUE` возвращает `4`, затем `1`;
- итоговые указатели: `head = 3`, `tail = 5`;
- в очереди остаются `3` и `8`.

### 10.1.4. Корректные ENQUEUE и DEQUEUE

Добавляется счётчик `count`:

- `count == 0` — очередь пуста, `DEQUEUE` завершается ошибкой underflow;
- `count == length` — очередь полна, `ENQUEUE` завершается ошибкой overflow;
- `head` и `tail` циклически переходят к началу массива.

### 10.1.5. Четыре операции дека

В циклическом массиве хранятся `head`, `tail` и `count`. Реализованы:

- `PUSH-FRONT` — вставка в начало;
- `PUSH-BACK` — вставка в конец;
- `POP-FRONT` — удаление из начала;
- `POP-BACK` — удаление из конца.

Все четыре операции выполняются за `O(1)` и проверяют переполнение/опустошение.
